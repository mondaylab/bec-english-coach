## 选题

按 `references/72-day-rotation.md` 先确定 Part、一级主题和 Level，再运行：

```bash
python3 scripts/feishu-corpus-select.py \
  --part "Part 2" \
  --theme "电子商务与新型工作方式"
```

选择器先查 `启用=true` 的记录，并按使用次数、最近使用日期和语料 ID 排序。如果没有可用记录，则返回一条 `待清洗` 记录并设置 `needs_curation=true`。

## 按需清洗

`needs_curation=true` 时：

1. 阅读原始题目、答题要点和原始参考答案。
2. 修正拼写、语法、搭配、过时表达和不自然的商务语气。
3. Part 1 答案控制在 2-4 句；Part 2 控制在约 90-130 词；Part 3 提炼成短轮次互动，不让学习者背长稿。
4. 保留原始观点中仍然有效的内容，不凭空添加事实、数据或公司案例。
5. 将结果写入 `清洗后参考答案`，将 3-6 个高价值短语写入 `可复用表达`。
6. 更新 `质量状态=["AI 已清洗"]`、`启用=true`。原始题目和原始答案不得覆盖。

只有人工明确确认过时，才把质量状态改为 `已确认`。

## Level 使用方式

- Level 1：展示清洗后的短参考答案，引导替换 2-3 个信息点。
- Level 2：第一次作答前只展示题目、答题要点和句型开头；之后再展示清洗答案。
- Level 3：先只展示题目和时间要求；反馈后再提供清洗答案作为对照。

语料记录上的 `难度` 表示推荐起始级别，不限制同一题目在更高级别中做变体或迁移。

## 训练回写

训练结束后：

1. 在训练记录表创建一条记录，并把 `使用语料` 关联到本次语料的 `record_id`。
2. 写入日期、Day、Part、主题、Level、用户回答、升级版本、最佳升级句和可评价的评分项。
3. 将语料的 `使用次数` 加一，并把 `最近使用` 更新为当天日期。
4. 需要复练时设置 `是否复练=true`、`训练状态=["待复练"]` 和下次复练日期。
5. 新发现的高价值表达写入表达库；重复表达优先更新现有记录的掌握状态和使用次数。
6. 反复出现的错误写入薄弱点表，并关联本次训练；近义问题合并更新出现次数。

没有音频或可靠转写线索时，不填写发音与流利度评分。

## 回填历史训练

本地已有练习摘要需要迁移或修复关联时，运行：

```bash
python3 scripts/feishu-practice-backfill.py
```

脚本把历史题目作为已确认的 `AI 生成` 语料写入题库，并关联训练记录。它同步练习中已确认的表达，只把至少重复出现两次的错误模式聚合进薄弱点表。没有可靠来源的评分不会补写。所有对象使用稳定 ID，可重复运行；再次运行不会覆盖云端的掌握状态、复练状态、评分或后续使用次数。
